
1. Select **Tenants** from the main navigation and click the **Add tenant** button:

   :::figure
   ![The Add tenant button on the Tenants page](/docs/img/shared-content/tenants/images/add-new-tenant.png)
   :::

2. Select if you want to **Add blank tenant** or **Clone an existing tenant**:

   :::figure
   ![Choosing between adding a blank tenant and cloning an existing one](/docs/img/shared-content/tenants/images/blank-or-clone-tenant.png)
   :::

3. Enter the name you want to use for the tenant and click the **Save** button:

   :::figure
    ![Entering a name for the new tenant](/docs/img/shared-content/tenants/images/creating-new-tenant.png)
   :::
