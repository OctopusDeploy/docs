This page covers feature flags in projects that haven't been upgraded to feature flag rules. If your project uses rules, see [Feature flags](/docs/feature-flags) instead. To move a project to rules, see [Upgrading to feature flag rules](/docs/feature-flags/upgrading-to-rules).
:::
