Update the variable snapshot for a runbook snapshot in Octopus Deploy

```text
Usage:
  octopus runbook snapshot snapshot-variables [flags]

Flags:
  -p, --project string    Name or ID of the project where the runbook is
  -r, --runbook string    Name or ID of the runbook
      --snapshot string   Name or ID of the snapshot to update variables for (defaults to the published snapshot)


Global Flags:
  -h, --help                   Show help for a command
      --no-prompt              Disable prompting in interactive mode
  -f, --output-format string   Specify the output format for a command ("json", "table", or "basic") (default "table")
  -s, --space string           Specify the space for operations

```

## Examples

<SamplesInstance />

```bash
$ octopus runbook snapshot snapshot-variables --project MyProject --runbook "Rebuild DB Indexes"
$ octopus runbook snapshot snapshot-variables --project MyProject --runbook "Rebuild DB Indexes" --snapshot "Snapshot 40C9ENM"


```
