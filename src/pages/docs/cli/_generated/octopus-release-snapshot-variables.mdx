Update the variable snapshot for a release in Octopus Deploy

```text
Usage:
  octopus release snapshot-variables [flags]

Flags:
  -p, --project string   Name or ID of the project
  -v, --version string   Release version/number


Global Flags:
  -h, --help                   Show help for a command
      --no-prompt              Disable prompting in interactive mode
  -f, --output-format string   Specify the output format for a command ("json", "table", or "basic") (default "table")
  -s, --space string           Specify the space for operations

```

## Examples

<SamplesInstance />

```bash
$ octopus release snapshot-variables --project MyProject --version 1.2.3
$ octopus release snapshot-variables -p MyProject -v 1.2.3


```
