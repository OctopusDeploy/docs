List tenant variables in Octopus Deploy

```text
Usage:
  octopus tenant variables list [<name> | <id>] [flags]

Aliases:
  list, ls

Flags:
  -t, --tenant string   The tenant


Global Flags:
  -h, --help                   Show help for a command
      --no-prompt              Disable prompting in interactive mode
  -f, --output-format string   Specify the output format for a command ("json", "table", or "basic") (default "table")
  -s, --space string           Specify the space for operations

```

## Examples

<SamplesInstance />

```bash
octopus tenant variables list "Bobs Wood Shop"
octopus tenant variables list --tenant "Bobs Wood Shop"
octopus tenant variables ls Tenant-123


```
