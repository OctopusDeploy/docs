Manage channels in Octopus Deploy

```text
Usage:
  octopus channel [command]

Available Commands:
  create Create a channel
  delete Delete a channel
  help Help about any command
  list List channels
  view View a channel

Global Flags:
  -h, --help                   Show help for a command
      --no-prompt              Disable prompting in interactive mode
  -f, --output-format string   Specify the output format for a command ("json", "table", or "basic") (default "table")
  -s, --space string           Specify the space for operations


Use "octopus channel [command] --help" for more information about a command.
```

## Examples

<SamplesInstance />

```bash
octopus channel create
octopus channel list --project myProject
octopus channel view "Hotfix" --project myProject
octopus channel delete "Hotfix" --project myProject


```
